# A2 独立站立支撑下的六关节伸收 · 2026-11-23

**两个历史留出均通过。** 六关节策略在停留段到世界目标的平均误差分别为 0.232 cm 和 0.127 cm。两条均完整执行 150 步、全程四脚着地，机身最大倾角约 2.42°。

## 输入与做法

继续使用自由浮动的 Go2＋PiPER 模型。独立的腿部 PD 控制器固定发送 12 个腿部站姿目标。每条从相同的 160 个物理步预站立开始。复用 `artifacts/reach_lr_20261119/{train_data,holdout_data}/calibrated/` 里的校准 IK＋PD 示范。脚和地面的接触仍由 MuJoCo 计算。既有示范本来就是固定腿部目标，所以先读出 6 个臂目标并重放，验证独立腿 PD 能重现原来的轨迹。第一轮训练只读取六条训练示范。

策略把目标相对手爪起点的**水平前向与侧向偏移**映射成 6 个峰值角度增量。用一个带截距的线性层拟合六个小范围平面目标。每拍用历史示范的五次曲线幅度乘峰值增量，再加到伸手预备姿态。曲线明确给出伸出、停留和收回时序，并在起止时使增量归零。目标的 Z 坐标用于验收，当前拟合使用平面任务输入。该策略在伸手前计算参考，底层关节 PD 每个物理步闭环。六条共 900 个关节目标样本，训练 1,200 次更新，动作均方根误差 0.00317 rad。训练在 CPU，CUDA 分配 0 MiB。同期整卡采样峰值 509 MiB，包含桌面等背景进程。见 [训练实测](../../artifacts/arm_reach/20261123_arm_bc_seed0/training_metrics.json)。

## 留出对照

停留窗口沿用 `[1.45, 1.70] s`。方向完成率是实际停留位移投影到示范位移方向后，相对示范位移长度的比例，超过 100% 表示该方向略有超伸。参考误差是相同帧到校准示范的手爪位置误差，到点误差是相同帧到固定空间目标的距离。收回残差是末帧相对首帧手爪位置的距离。

验收为方向完成率 ≥70%、停留参考误差 ≤2.5 cm、机身最大倾角 ≤5°、全程四脚接触。留出目标和校准参考与历史结果相同。历史策略使用 Warp，本次使用 CPU MuJoCo，策略结构和输入也不同。结果反映这两套方案的整体差异。A2 的停留误差更小，同时末帧收回残差比历史策略大约 0.62–0.74 cm，接近其校准示范。见 [逐条指标](../../artifacts/arm_reach/20261123_arm_bc_seed0/holdout/metrics.json)、[左侧视频](../../artifacts/arm_reach/20261123_arm_bc_seed0/holdout/reach_00/comparison.mp4) 与 [右侧视频](../../artifacts/arm_reach/20261123_arm_bc_seed0/holdout/reach_01/comparison.mp4)。

## 复现

在 WSL Ubuntu 仓库根目录执行。复用历史 PyTorch/MuJoCo 环境和校准 NPZ。用新运行名保留已有产物。

```bash
r=20261123_arm_bc_repro_seed0
bash experiments/arm_reach/run.sh train --run "$r"
bash experiments/arm_reach/run.sh holdout --run "$r"
bash experiments/arm_reach/run.sh video --run "$r"
```
