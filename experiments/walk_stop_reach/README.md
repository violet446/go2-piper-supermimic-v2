# B 同一回合走停伸收 · 2026-11-23

**B1 在两个留出场景完成走、停、伸、留、收回和重新收拢。** 两条停留平均到点误差为 0.541 cm、0.726 cm，无跌倒，停车后四脚全程着地。B2 联合模仿也通过两条留出。B2 的到点误差变化小于 0.005 cm，停车后的机身漂移幅度几乎相同。当前选用 B1 作为组合基线。

## B1 模块串联

使用 A1 `20261120_bc_seed0` 和 A2 `20261123_arm_bc_seed0` 的实际权重。回合开头在已知起点站定，从名义停车点和局部偏移计算一次世界目标并记入轨迹。开发样例采用 25 cm 停车距离。参考手爪预备点相对名义停车点的局部 XY 为 `(7, 0) cm`，Z 为 `95.55 cm`。这组数来自开发场景中测到的预备姿态并取近似值。给该预备点加左右偏移得到各场景的固定世界目标。正式留出执行前冻结配置与权重哈希。

1. **走和停。** A1 走满 16.26 s。位置误差 ≤5 cm、朝向误差 ≤10°，最后 0.5 秒四脚着地且水平速度始终 ≤0.05 m/s，同时通过 A1 的其他冻结检查，才进入交接。
2. **交给站立控制。** 将 A1 最后一次发送的 12 个腿关节目标作为交接第一拍，按五次曲线用 1.2 秒平滑变到 A2 的独立腿部站姿目标。随后用 2.0 秒把机械臂从 A1 的收拢位移到 A2 的伸手预备位，再保持 0.6 秒并确认仍在停靠区、末窗四脚与速度达标。这些控制全部作用在前一阶段的真实 MuJoCo 状态上。
3. **伸手再收回。** 从当前手爪位置和实际机身朝向计算去往固定世界目标的相对请求，再用 A2 做 3.0 秒的伸收。到达量测用历史 `[1.45, 1.70] s` 停留窗。收回残差以实际进入伸手前的手爪位置为零点。最后用 2.0 秒重新收拢 PiPER，再保持 0.6 秒。总长 **25.66 秒**。

额外检查停车后的最大位置误差仍 ≤5 cm、停车后全程四脚支持、整回合无跌倒、停留到固定目标 ≤2.5 cm、臂最终回到收拢目标的最大实际角差 ≤0.20 rad。B1 开发样例通过后冻结配置，才执行下表的正式留出。两条世界目标分别为 `(0.412347, −0.016652, 0.955500) m` 和 `(0.287909, 0.012662, 0.955500) m`。

## B2 联合模仿对照

B1 的停车后最大位置误差增至 1.53–1.55 cm，相对独立 A2 的停留到点误差增加约 0.31、0.60 cm。为测联合训练能否缩小这些差异，在 20–30 cm 的六个训练距离各采集一左一右，共 12 条 B1 整机示范。全回合保存 18 个关节目标、初始物理状态、阶段、位姿和接触。每条均通过 B1 门槛，保存目标独立推进物理，位姿、速度和接触逐帧完全一致。

B2 使用共享神经网络主干，走路端和伸手端各输出 18 个目标的修正。主干与走路端的腿部用 A1 初始化。伸手端从零拟合 B1 的臂动作和腿部站姿。每次更新同时计算走路段与伸手段的监督损失。12 条全回合中，采用 **9,756** 个走停帧与 **1,800** 个伸收帧训练，平滑交接、预备和重新收拢继续使用 B1 的确定性命令。训练 2,500 次更新，整卡采样峰值 **906 MiB**、PyTorch 峰值已分配 **29.75 MiB**。行为克隆的标签来自 B1，训练目标是复现其动作，因此本轮主要测联合模型能否复现原来的闭环轨迹。见 [示范清单](../../data/walk_stop_reach/20261123_joint_seed0/manifest.json) 与 [训练实测](../../artifacts/walk_stop_reach/20261123_b2_joint_bc_seed0/training_metrics.json)。

## 复现与视频

WSL Ubuntu 仓库根目录执行。默认依赖正式 A1 与 A2 权重，继续复用历史运行环境。先跑开发，再跑留出。

```bash
entry=experiments/walk_stop_reach/run.sh
b1=20261123_b1_repro
b2=20261123_b2_repro_seed0
dataset=20261123_joint_repro_seed0
bash "$entry" development --run "$b1"
bash "$entry" holdout --run "$b1"
bash "$entry" video --run "$b1"
bash "$entry" joint train --run "$b2" --b1 "$b1" --dataset "$dataset" --device cuda
bash "$entry" joint development --run "$b2"
bash "$entry" joint holdout --run "$b2"
bash "$entry" video --run "$b2"
```

逐条 `metrics.json` 保存真实世界目标、停车和伸手指标、阶段时间戳。逐帧 `rollout.npz` 保存初始、确认停稳及开始伸手的完整积分状态，以及时间、每拍执行的 18 个目标角和接触数据。视频中绿色平面点标示停车位置，橙色空间点标示抓手固定目标。
